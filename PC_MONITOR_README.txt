TIKTOK LIVE BATTLE ARENA - PC MONITOR

Dit onderdeel is voor de oude Windows 7 32-bit pc.

Op de pc:
1. Start de game/server zoals in de hoofd-README.
2. Dubbelklik op OPEN_PC_MONITOR.bat.
3. De browser opent http://localhost:3000/pc.html

De pc-monitor is bedoeld als tweede scherm/controlestation.
De game voor kijkers blijft op de telefoon staan.

LET OP:
- Dit is een lichte webmonitor; hij hoeft geen zware game te renderen.
- De echte TikTok LIVE-koppeling moet op de server draaien.
